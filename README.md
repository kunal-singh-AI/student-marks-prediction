# Student Marks Prediction

A beginner machine learning project that predicts student marks based on study hours using Linear Regression.

## 📌 Project Overview

The goal of this project is to understand the basic end-to-end machine learning workflow by building a simple regression model.

The model learns the relationship between:

- Study Hours — Input Feature
- Marks — Target Variable

## 🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

## 🔄 Machine Learning Workflow

1. Created the dataset
2. Explored the data
3. Visualized the relationship using a scatter plot
4. Selected the input feature and target variable
5. Chose Linear Regression
6. Trained the model
7. Made predictions
8. Evaluated the model using:
   - MAE
   - MSE
   - R² Score

## 📊 Model

**Algorithm:** Linear Regression

The model uses study hours to predict student marks.

## 🎯 Example Prediction

The model was used to predict the marks of a student who studies for 6 hours.

The predicted result was approximately **80 marks**.
